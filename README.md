# UEFI x64 OS 개발 프로젝트
UEFI를 기반으로 동작하는 64비트 멀티코어 GUI 운영체제를 개발해보자

## 구현된 기능
### 부트로더
- OS Loader 불러오기
### OS Loader
- 페이징 테이블 재설정
- 그래픽 모드 설정 (FHD로 설정, 미지원 시 지원하는 최대 해상도)
- 메모리 맵 불러오기 및 용량 검사

## 구현할 기능
### 부트로더
- 부팅 가능한 파일 검색
- 운영체제 선택창 구현
### OS Loader
- 시스템 요구 사항 검사
- ACPI 테이블 읽어오기
- ELF 커널 불러오기
### 커널
- 간단한 로딩화면 출력
- 문자열 출력 구현
- 인터럽트 구현하여 키보드 입력 받기
